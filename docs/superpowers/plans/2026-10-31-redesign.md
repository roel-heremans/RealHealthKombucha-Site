# Real Health Kombucha Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Framer-faithful phase-1 site with a Sattva-style, bilingual (EN/PT), pitch-based site of 7 pages, keeping the build/preview/deploy pipeline.

**Architecture:** Same generator (`src/content.py` → `src/build.py` → Jinja2 templates → `output/`). Content values that differ per language are `{"en": ..., "pt": ...}` dicts resolved by a `t` filter; each page is rendered once per language under `/` and `/pt/`. Image preparation is a reproducible script reading Roel's asset folders. App screenshots come from a local, stubbed copy of the orders app.

**Tech Stack:** Python 3, Jinja2, pytest, ImageMagick (`convert`) for image prep, headless Google Chrome for screenshots, GitHub Actions → GitHub Pages (unchanged).

**Spec:** `docs/superpowers/specs/2026-10-31-redesign-design.md` (approved visual reference: `docs/design/direction-a-forest.png`).
